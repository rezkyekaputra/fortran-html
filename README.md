# fortran-web 🌸

Demo website yang di-generate oleh **GNU Fortran 14.3.1** via CGI.

## Cara pakai

```bash
# 1. Clone
git clone <repo-url>
cd fortran-web

# 2. Compile Fortran
gfortran -O2 -o cgi-bin/hello cgi-bin/hello.f90

# 3. Jalankan server
python3 server.py

# 4. Buka browser
xdg-open http://localhost:8080
```

## Struktur

```
fortran-web/
├── cgi-bin/
│   ├── hello.f90   ← Source Fortran
│   └── hello       ← Binary compiled
├── www/
│   └── index.html  ← HTML pre-generated
├── server.py       ← CGI server (Python)
└── README.md
```
